# drama-studio

Плагин Claude Code для роликов-драм в стиле «ИИ-мультсериалов»: семи-реалистичная 2D-иллюстрация, одни и те же герои во всех кадрах, оживлённые нейросетью сцены, диалог голосами персонажей, вставки документов-улик, жёсткий монтаж.

## Установка
```
/plugin marketplace add id7775/telegram_autoreg
/plugin install drama-studio@id7775-plugins
```
Нужны Node 18+, ffmpeg и curl. Для автогенерации нужен ключ fal.ai (`FAL_KEY`). Без ключа работает ручной режим: плагин выдаёт промпты, а генерируете вы сами.

## Как пользоваться
Напишите Claude: «сделай драму про …» или «сделай ролик как этот» и приложите видео. Можно вызвать напрямую: `/drama-studio:drama-video`.

Пайплайн: анкета → сценарий → бесплатный аниматик на заглушках → листы персонажей → кадры → голоса → оживление (Kling) → монтаж с музыкой и субтитрами → `out/final.mp4`.

Движок: `skills/drama-video/scripts/studio.mjs`. Команды: `node studio.mjs help`.
